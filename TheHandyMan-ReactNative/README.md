# The Handy Man

## Overview

The Handy Man is a React Native application designed to connect homeowners with service professionals. Users can register, log in, and book services through the app. The application features a user-friendly interface and efficient navigation to enhance user experience.

## Features

- User authentication (registration and login)
- Dashboard for homeowners and service professionals
- Booking services
- Messaging functionality
- Responsive design

## Getting Started

### Step 1: Clone the Repository

Clone the repository to your local machine using the following command:

```bash
git clone <repository-url>
```

### Step 2: Navigate to the Project Directory

Change into the project directory:

```bash
cd TheHandyMan-ReactNative
```

### Step 3: Install Dependencies

Install the required dependencies using npm or yarn:

```bash
npm install
```
or
```bash
yarn install
```

### Step 4: Run the Application

To run the application on Android, use:

```bash
npx react-native run-android
```

To run the application on iOS, use:

```bash
npx react-native run-ios
```

### Step 5: Additional Setup

For navigation and UI components, you may want to install additional libraries. For example, to set up React Navigation, run:

```bash
npm install @react-navigation/native @react-navigation/native-stack
```

And install the required dependencies for React Navigation:

```bash
npm install react-native-gesture-handler react-native-reanimated react-native-screens react-native-safe-area-context @react-native-community/masked-view
```

### Conclusion

You have successfully set up The Handy Man application. Feel free to explore the codebase and contribute to the project!
